# 🐐 Olá, eu sou o Hugo
**`Desenvolvedor Full Stack`**

## Sobre mim
- Estudante de Análise e Desenvolvimento de Sistemas na FIAP.
- Apaixonado por tecnologia e principalmente por experiência do usuário.
- Faço com que problemas reais sejam solucionados através de códigos e aplicações.
- Do front ao deploy: construo interface, API, banco de dados e coloco no ar.

## O que estou estudando e construindo
- **Front-end:** React + TypeScript, Vite e Tailwind CSS
- **Back-end:** Node.js com Fastify, Knex.js, autenticação JWT e APIs REST em TypeScript
- **Mobile:** ReactNative, Flutter e Dart
- **Banco de dados:** SQL (Oracle SQL / PL-SQL), SQLite e Supabase
- **Infra e deploy:** Vercel, Render, Docker e Azure
